# 第十三章 平台、协议与新的计划性

## 13.1 协调成本的迁移而非归零：从人际摩擦到协议基础设施

在关于智能代理与去中心化自治组织的乐观叙事中，一种广为流传的技术乌托邦构想是：随着个人代理能够自动化处理谈判、合约签署与跨主体协同，人类社会将迅速迈入一个交易成本与协调摩擦彻底归零的时代，进而自然实现马克思意义上“自由人的自由联合”。

然而，正如第十一章所指出的（详见 §11.3），这种将 $C_{Demande \to R}$ 的下降等同于无条件解放的观点，落入了布洛赫所批判的“抽象乌托邦”[[Bloch, 1959](refs.md#bloch1959_prinzhoffnung_version)]（词条梳理参[[Zudeick, 2012](refs.md#blochwb_utopie)]）。在当代社会技术系统的深层结构中，**协调成本绝非凭空消失，而是经历了一场系统性的结构迁移**：

$$\text{Coordination Cost: } \text{Interpersonal Friction} \longrightarrow \text{Platform \& Protocol Infrastructure}$$

在传统社会中，协调成本主要沉淀在人与人之间面对面的沟通、说服、博弈与信任建立之中；而在由 Agent 生态深度中介的网络中，人际维度的摩擦虽然大幅降低，但维持大规模跨生态协作所需的系统成本，被全面转移并固化在底层的平台与协议层中：
1. **身份认证与声誉协议成本**：在大量自主代理并发交互的网络中，如何验证代理背后的真实主体身份、评估代理的履约信誉并防范女巫攻击（Sybil attack），需要依赖极其复杂的密码学验证与去中心化标识符（DID）协议[[Hadfield and Koh, 2025](refs.md#hadfield2025_economy_agents); [Weyl et al., 2022](refs.md#weyl2022_decentralized_society)]；
2. **算力配额与 API 访问门槛**：代理的高频链式推理与工具调用高度依赖云端算力，API 调用费率、网络带宽与速率限制构成了现实化链条中不可逾越的物质成本；
3. **平台对齐规则与合规审核**：如第十一章所述，平台的服务条款（ToS）与内容安全过滤系统构成了实时的准入门禁（详见 §11.3）；
4. **互操作性与格式转译协议**：不同厂商与开源生态的代理之间若想实现无缝协作，必须依赖标准化的通信协议与语义对齐机制；
5. **支付轨道与清算接口（Payment Rails）**：代理间高频小额交易与跨生态资源结算，依赖于受监管的数字支付通道与清算网络；
6. **私有数据与知识库访问（Data Access）**：高质量领域数据与动态知识库的授权调用，构成了维系代理专业能力的长期制度成本。

因此，科斯式交易成本的下降，并没有带来纯粹无摩擦的自治领域，而是可能将权力的支点重构为中心化的数字基础设施。必须指出，以下关于平台权力与协议控制的分析，均作为结构性风险而非确定性预测陈述。

## 13.2 模块化与集中并存的双重拓扑：去中心化端侧与中心化算力底座

与协调成本迁移相伴随的，是 Agent 社会在产业架构与权力分布上所呈现出的**双重拓扑格局（dual topological structure）**：

### 1. 端侧与应用层的去中心化与模块化
在终端应用与微观生态层面，开源模型、轻量化量化技术以及端侧本地推理的成熟，使个体与小型组织能够以较低的门槛部署私有化的专用代理生态。各具特色的领域代理、角色提示词与本地知识库呈现出繁荣、分散且去中心化的模块化网络。行动者在端侧拥有较高的自组织自由，能够针对个性化要求进行灵活的任务编排。

### 2. 基础设施层与基座模型的高度集中
然而，端侧模块化的繁荣并不排除底层基础设施的高度集中。超大规模前沿基础模型的预训练、超大规模异构算力集群的运维、底层芯片制造供应链以及跨国能源与网络基础设施，高度集聚在少数全球性算力与模型提供商手中。前沿基座模型所拥有的世界知识与基础推理能力，构成了下游轻量级代理不可脱离的算力与模型基础。

这种“端侧模块化 + 底座中心化”的并存结构意味着，智能代理时代未必打破权力的集中，而是可能将权力上移至更为抽象、更为隐蔽的模型权重与协议标准之中。主体的技术自足在表层上获得了极大的行动自由，但在深层上却牢固地锚定在少数中心化基础设施的支撑之上。

## 13.3 新的计划性与资本主义话语：闭环及其不可消除的剩余


基础设施的高度集中与端侧代理的深度渗透，可能形成一种新型的社会协调与控制机制——**新的计划性（platform planning）**。

必须强调，这种新的计划性既不同于20世纪国家层面的官僚指令性计划经济，亦不同于古典自由放任的市场自发秩序。它是在资本逻辑与控制论技术深度交织的背景下展开的：平台通过对全社会海量代理交互数据的实时捕获、意图分析与行为预测，在微观层面上展开实时的资源调度与偏好引导。平台算法并不需要像传统计划委员会那样直接下达指令配额，而是通过调整 API 接口策略、安全对齐边界与推荐参数，对全社会的“要求”（demande）进行算法化的事前塑造与事前审查。

在拉康精神分析视域下，这种机制精准地契合了拉康在1972年米兰讲演中所诊断的**“资本主义话语”（Capitalist Discourse）**[[Lacan(1972{\natexlab{a}})](refs.md#lacan_milan_1972_version)]。拉康指出，资本主义话语的根本特征在于它试图抹除象征界与实在界之间的不可逾越之深渊，向主体许诺“没有不可能性”：在这一话语结构中，被划杠主体（$\bar{S}$，四话语图式中通写作 $\$$）直接向能指主词（$S_1$）发号施令，能指转向技术知识与算法系统（$S_2$），系统源源不断地生产出占据剩余享乐位置的技术客体（$a$），进而形成无阻断的消费与增殖闭环。

在资本主义话语的诱导下，主体被告知：所有匮乏都能够通过消费最新的技术客体与智能服务得到完美填充；平台系统作为掌握全面知识的能指，能够生产出精准匹配每一个具体要求的智能客体。资本逻辑试图将人类欲望完全驯化为可被数据捕获的“偏好”，进而将主体的生命动力收编在“提出要求—算法应答—资本增殖”的闭环回路之中。这一话语的主体层具体形态，是第十五章情景 A 的内极限：只与 Agent 交互、要求频率持续上升的主体，正是它的理想用户。

然而，正如第二章的核心命题所确立的：**剩余不能被计划（The Remainder Cannot Be Planned）。**

资本主义话语对完全自洽闭环的许诺，注定是一场无法实现的幻想。无论平台的合规预筛多么严密、基座模型的对齐算法多么精巧，Agent 所能穷尽交付的永远只是符号化的要求，而主体被划杠的结构（$\bar{S}$）与未被符号化的实在界剩余（remainder）始终顽固存在。当用户在同质化的平台交付物面前再次遭遇无法被技术抚平的剩余时，实在界的裂缝便再次显化。

由此，平台协议所构建的新计划性并未终结矛盾，而是把剩余重新定位于**模型合规的边界、真实他者的承认，以及不可计算的集体决断之处**；这三处正是 Agent 社会中主体重新出现的核心位置（详见 §10.3），其具体的社会演变走向由第十五章的三种竞争情景所系统刻画（详见 §十五）。
