# 第十二章 从价值对齐到欲望—智能体回路（Desire–Agent Loop）：递归动力学与剩余的再定位

## 12.1 从价值对齐到欲望问题：一个更前置的提问

在当代人工智能伦理、安全与对齐（alignment）研究中，主流范式建立在行为主义与功利主义的技术框架之上[[Ouyang et al., 2022](refs.md#ouyang2022_instructgpt); [Bai et al., 2022](refs.md#bai2022_constitutional_ai)]。该范式的基本逻辑可以形式化地表述为：
$$\text{Human Values / Preferences} \longrightarrow \text{Agent Goal} \longrightarrow \text{Action}$$

在这一标准模型中，人类主体的“价值”（values）或“偏好”（preferences）被预设为一种外生给定、静态存在且在原则上可通过提问、评分或历史数据反向推断的完备函数（$P$）。对齐的核心工程任务，在于设计优化算法与安全约束，确保智能系统（Agent）在推断和执行该目标函数时不发生越轨，从而实现对既定人类偏好的高保真满足。

本文明确指出，这一对齐范式对于防范系统失控、权力滥用与直接技术伤害是极其必要且不应被贬低的。然而，在社会理论与主体哲学层面，近期的前沿研究已经指出该模型在理论前设上的局限性：
1. **策略诱导的偏好漂移**：在强化学习与算法交互回路中，系统对用户偏好的迎合本身就会参与重塑用户的后续偏好函数，导致偏好的内生动态漂移[[Carroll et al., 2022](refs.md#carroll2022_estimating_penalizing); [Carroll et al., 2024](refs.md#carroll2024_alignment_changing)]。
2. **规范固着的社会学风险**：将特定历史时刻的人类价值函数作为固定基准进行硬编码对齐，可能带来社会规范演化锁死的风险，限制社会在技术变迁中协商生成新规范的可能空间[[Tomašev et al., 2026](refs.md#tomaev2026_value_alignment)]。
3. **组织装配中的价值转化**：在管理学与技术社会学视域下，智能代理在工作程序中的嵌入不仅执行既定价值，更直接将宣称的价值（espoused values）重塑为实践中的生成价值（enacted values）[[Glaser et al., 2026](refs.md#glaser2026_axiology_agents)]。

上述批评已由相关前沿研究提出，本文在此基础上进一步深化。对齐范式所聚焦的核心问题是“机器如何忠实于既定目标”，而本文并不否定这一问题，而是在其前后各补充一个被略去的根本追问：
- **前置追问**：人类的目标与欲望究竟从何而来？
- **后置追问**：当技术系统以极高效率执行并交付了目标之后，主体与社会现实中究竟留下了什么？

如果智能代理不仅执行要求，更通过重构现实而反向参与了人类下一轮动机的生成环境，那么线性的对齐模型就应当被补充为一个内生的、递归的动力学模型。

## 12.2 Desire–Agent Loop 的形式化构建与五阶动力学

为了完整解释 Agent 社会中欲望、技术执行与社会结构之间的共同演化机制，本文在全文中**唯一正式确立**如下动力学回路模型——**Desire–Agent Loop**：

$$D_t \longrightarrow \text{demande}_t \longrightarrow G_t \longrightarrow \mathcal{A}_t \longrightarrow R_t \longrightarrow \text{rest}_t \longrightarrow D_{t+1}$$

该回路并非抽象的循环论证，而是包含了五个严格递进的动力学转化阶段：

### 阶段一：欲望的表达与要求形式化（$D_t \to \text{demande}_t \to G_t$）
人类主体的深层动力源泉，在于源自被划杠主体（$\bar{S}$）内在匮乏、面向不可能者（the impossible）的拉康式欲望（$D_t$）[[Lacan, 2006](refs.md#lacan_ecrits_complete_version)]。然而，欲望不以可编码输入的形式进入计算系统；主体在象征界中所能提出的只能是指向尚未存在之物的具象“要求”（$\text{demande}_t$）。随后，这一要求在人机交互界面中被进一步形式化为带有明确参数约束、评测指标与执行步骤的操作目标（$G_t$）。在此，欲望经由要求被表达但不被要求穷尽；进入计算编码的是要求，交付之后留存的是未被符号化穷尽的剩余（$rest_t$），欲望围绕它重新定位（$D_{t+1}$）——回路中 $D_t$ 与 $rest_t$ 是两个节点。

### 阶段二：生态级并发执行与现实重构（$G_t \to \mathcal{A}_t \to R_t$）
操作目标 $G_t$ 被派发至主体的 Agent 生态（$\mathcal{A}_t$）。异质代理集群利用大幅降低的要求现实化成本（$C_{Demande \to R}\downarrow\downarrow$），在数字与物理网络中展开高强度的自动化协作，越过漫长的传统人际协调摩擦，在极短的时空窗口内完成生产、谈判与交付，从而将抽象目标直接转化为可观测的物质与制度现实（$R_t$）。

### 阶段三：交付的达成与剩余的显化（$R_t \to \text{rest}_t$）
当代理生态将契合提示词要求的最终结果交付给主体时，主体遭遇了关键的结构性落差：**“我得到的正是我所要求的，但它依然不是我所欲望的。”**
因为 Agent 穷尽执行的仅仅是符号化的“要求”（demande），而欲望（desire）在本体论上正是要求被满足后依然顽固留存的不可化约之物[[Lacan, 2006](refs.md#lacan_ecrits_complete_version)]。交付的达成，使未被符号化吞噬的实在界剩余（$\text{rest}_t$）直接显化在主体面前。

### 阶段四：剩余对欲望的重新定位（$\text{rest}_t \to D_{t+1}$）
在传统社会中，漫长的执行摩擦掩盖了这种剩余；而在 Agent 社会中，自动化的快速交付使主体以更高的频率直面剩余。正是这一剩余的存在，松动了主体对先前经验客体的幻想固着，使占据对象 a 位置的具体客体发生更替（而作为欲望之因的对象 a 本身在结构上保持恒定），欲望由此被重新定位，进而在新的可能域边界上催生出下一轮形态各异的新要求与新欲望（$D_{t+1}$）。

### 阶段五：递归迭代
新欲望 $D_{t+1}$ 驱动主体提出新的要求 $\text{demande}_{t+1}$，进而配置新一代的代理生态 $\mathcal{A}_{t+1}$，驱动社会技术系统进入下一轮递归循环。

## 12.3 剩余的重新定位与社会环境的递归协同演化

在上述回路中，一个关键的理论问题在于：社会环境与技术生态的宏观变迁，究竟在哪个节点介入了微观主体的精神动力学？

技术决定论式的读法会认为“技术环境（$S$）直接决定了人的欲望（$D$）”。本文的 Desire–Agent Loop 拒绝这种机械反映论。
在本文的模型中：

$$\text{新社会环境 } S_{t+1} \text{ 绝非直接注射欲望，而是通过调节剩余（}\text{rest}_t\text{）出现的空间、频率与可见性来发挥作用。}$$

当整个社会步入人—Agent 生态深度中介的形态后，社会环境 $S_{t+1}$ 发生了三重结构性重塑：
1. **交往拓扑的重构与承认维度的位移**：如第六章所述，功能性人际脱媒导致个体在现实中遭遇真实他者偶然拒绝的频率下降，使人机界面的技术剩余增加；同时，正如统一核心句所指出的，**真实他者的自愿承认**作为无法被代理自动化交付者，成为剩余重新定位的核心场所（详见 §六 与 §九）；

2. **制度预筛规则的固化**：如第十一章所述，平台对齐规则与协议准入标准重新划定了要求的合规边界，从而将不可交付的剩余推移至平台许可的边界地带；
3. **交付周期的显著缩短**：要求从发出到交付的时间差大幅缩短，使得主体与剩余的遭遇从偶发事件转变为高频的日常体验。

正是在这一重构后的社会技术环境 $S_{t+1}$ 中，剩余（$\text{rest}_t$）获得了一个新的坐标系。剩余的位置从传统稀缺条件下的“无能为力”，转变为工具高度可用条件下的“交付后未及”。

由此，Desire–Agent Loop 最终表明：**Agent 使要求的执行近乎自动化，因而使欲望的剩余更快、更并发、更可见地重新出现。** 它未曾消除主体的分裂与匮乏，却构成了人类欲望在现代技术条件下持续重新定位的社会动力学闭环。
