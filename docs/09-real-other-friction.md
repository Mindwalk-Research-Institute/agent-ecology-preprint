# 第九章 真实他者、摩擦与要求/欲望的形成

## 9.1 真实他者的不可还原性：不透明性、拒绝能力与意外反馈

在传统的人机交互与智能代理设计话语中，外部世界往往被抽象为一个由数据流、API 接口与资源约束构成的客观环境；相应地，除主体之外的其他人类个体，则容易被简化为“外部环境中的服务提供者”、“博弈中的理性竞争者”或“协同生产中的功能性节点”。然而，在社会哲学与主体精神动力学的深层视野中，真实他者（concrete others）在社会构成中所扮演的角色，绝不能被等同于可预测、可参数化的计算环境组件。

真实他者的本质特征，在于其具有独立欲望、不可完全消除的**不透明性（opacity）**、自主的**拒绝能力（capacity to refuse）**、产生**误解与未预期反应**的不可预测性，以及**改变自身偏好与行动策略的能力**。在传统协作中，真实他者的拒绝能力在实质上构成了一种人际否决权；在人与人的直接交往中，他者从来不是一个对主体的指令做出线性确定性响应的执行实体；相反，他者拥有自身的历史经验、意图缝隙、情感防御与未被符号化的无意识动能。

这种不透明性与拒绝能力，并非社会交往中应当被技术手段彻底抹除的“噪声”或“摩擦损耗”，而是人类主体性确立的前提。正是由于他者可能误解我们的表达、拒绝我们的提议、提出意料之外的反驳，乃至打破我们预设的交往剧本，主体的自我中心主义才得以被客观现实所打断。换言之，正是真实他者的不可支配性，构成了个体走出纯粹想象界幻觉、确立象征界规范意识并遭遇实在界界限的基本社会条件。

## 9.2 人际摩擦与主体的生成：偏好重塑与欲望激发的双重路径

为了精确剖析人际交往中的摩擦如何参与人类动机的生成，必须严格拆解两个在传统讨论中常被混为一谈的概念维度：**偏好（preferences）的经验重塑**与**欲望（desire）的结构激发**。

### 1. 偏好的经验重塑：社会化与理性协商路径
在经验社会学与理性选择理论视域下，主体的偏好从来不是孤立、完备且先验给定的，而是在与外部他者的互动反馈中动态演化生成的[[Sen, 1977](refs.md#sen1977_rational_fools); [Bowles, 1998](refs.md#bowles1998_endogenous_preferences)]。当个体在现实协作中提出某项方案时，他者的抗议、还价或拒绝迫使主体重新权衡成本收益，修正自身对可行性边界的评估，进而调整其后续提出的具体“要求”（demande）。在此，人际摩擦作为一种社会化机制，促使主体在经验层面上将他者的合理利益纳入自身的效用考量，完成了偏好的情境化重塑。

### 2. 欲望的结构激发：精神分析与大他者路径
然而，在拉康精神分析视域下，深层的欲望（desire）绝非经验偏好的数学加权，而是具有完全不同的发生学逻辑——**“人的欲望是他者的欲望”（le désir de l'homme est le désir de l'Autre）**[[Lacan, 2006](refs.md#lacan_ecrits_complete_version)]。欲望之所以被点燃，恰恰是因为他者具有不可穿透的神秘性与不可占有性；主体在他者的目光、言说与沉默中不断追问：“你到底想要什么？（*Che vuoi?*）”，进而在他者不可测度的欲望之谜中为自己的匮乏寻找坐标。如果他者是一个完全透明、绝对顺从且毫无保留的机械自动化客体，欲望便会因失去匮乏的间距而失去支点。

在此必须指出：**Agent 作为被委托的计算代表者，不占据欲望的他者位置**。这不是关于 Agent 内心的心理学断言，而是一个位置论命题：Agent 不占据被划杠大他者的位置——它不匮乏，因而没有标记其匮乏的能指（§7.1 所用的 $S(\bar{A})$），主体的欲望无从围绕它的匮乏组织，“你到底想要什么”的追问在它面前没有着落点；若说有什么更接近大他者候选位置的东西，那是平台层的规则与协议系统，而非具体运行的 Agent（§14.6）。因此，Agent 生态的交付物无法充当欲望之因（objet a），至多暂时占据对象 a 的位置（§3.3）；其交付只能停在要求的平面上，在其身后留下不可交付的剩余（这一位置论前提的结构论证见 §10.2，剩余的位置见 §10.3 与 §十二）。

如第六章所述，随着功能性交往向 Agent 生态转移，人与人之间为了“达成世俗事务”而不得不进行的直接人际摩擦相应减少。在这一背景下，关于**承认、爱、伦理责任与政治分歧**的非功能性关系在人类直接互动中的占比**可能**相对上升（情景 B，详见 §十五）；这一结构变化是否发生，构成了经验研究的重要检验对象。

## 9.3 遭遇性质的拓扑位移：从工具性捆绑到承认剩余的加速显化

因此，Agent 生态对人类社会关系的重塑，其关键不在于“消除人际交往”，而在于**系统性地改变了人类遭遇他者的性质与拓扑结构**。

在传统社会结构中，人与他者的遭遇主要表现为一种**“工具性捆绑”**：为了实现生活生存的具体功能性目标，个体被迫卷入复杂的现实人际网络，在漫长的人际周旋中附带性地体验到他者的异质性与偶然性连结。而在由 Agent 生态深度中介的社会中，社会交往发生了关键的分流：
- 一方面，个体凭借技术自足（technical self-sufficiency），在解决具体功能性诉求时可能选择退入高度闭环的技术微型系统，从而在日常事务中提前规避与真实他者的直接碰撞；
- 另一方面，当个体必须走出技术堡垒去面对他人时，所遭遇的不再是工具性的配合问题，而是纯粹的、不可通过计算协议予以自动交付的主体间性议题。

本文在此**正式确立**核心理论命题：**Agent 生态并未成为逃避主体遭遇的被动避难所，而是构成了加速并显化欲望剩余的技术装置**（以回路不退化为条件，见 §十五 情景 A 内极限；第十一章 11.1 对交互被动性的回应即依赖于本章的这一论断）。

当个人代理以极高的工程保真度满足了主体所发出的一切符号化要求（如精准完成了代码交付、商业谈判与日常事务调度）时，主体在世俗工具层面不再遭遇任何阻碍。然而，正如统一核心命题所指出的，**无论代理系统的执行能力多么强大，它在结构上无法替主体自动化交付真实他者的自愿承认与爱**。


在此，未被计算系统吞噬的实在界剩余（remainder），以不可回避的清晰度被推至主体面前：它不再混杂于“对方是否按时交货”或“排期是否冲突”等技术性烦恼之中，而是直接聚焦于“他者是否真正承认我、接纳我并在伦理上与我共同存在”。

必须强调，**加速遭遇剩余在社会后果上具有明确的双刃性**，并在微观经验中展现为一系列可观察的指标：主体的具体操作目标快速更替、“要求被应答后即刻产生空虚与不满”，以及“符号化要求已被完全穷尽但精神依然悬空”的普遍体验。这一加速机制本身并不预定解放方向：它既可能驱使主体直面真实匮乏并重新定位欲望，亦可能被平台化的即时反馈与算法推荐回路所吸收，滑入资本主义话语式的成瘾循环（详见 §13.3 与 §十五）。由此，Agent 生态将人类推向了一个在高度自足与剩余显化之间持续震荡的社会技术场域。
