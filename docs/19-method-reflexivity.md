# 第十九章 研究方法、反身性与限度声明

## 19.1 方法论定位：当下史描述而非结构性预言

本文在方法论上拒绝采取两种常见但具有误导性的理论姿态：既不采取实证主义式的未来技术预测（futuristic forecasting），亦不滑向目的论式的历史推演。

本文的方法定位严格确立为**对一个正在浮现之技术部署（dispositif）的“当下史描述”（History of the Present）**[[Agamben, 2009](refs.md#agamben2009_what_is_an_apparatus); [Foucault, 1977](refs.md#foucault1977_discipline_punish); [Deleuze, 1989](refs.md#deleuze1989_what_is_dispositif)]。在福柯与德勒兹的谱系学视域下，当下史的旨趣不在于预言未来的必然终局，而在于深入正在展开的当下实践，诊断当前的技术拓扑、制度协议与话语网络（经验基线见 §1.8）如何交织构成一套新的行动机制，并追问在这一装置中：
1. 哪些先前被视为不可行动的私人要求获得了现实化的技术效能？
2. 主体化（subjectivation）的实践形式正在发生何种结构性重构？
3. 不可消除的实在界剩余被推向了哪些新的拓扑位置？

通过将 Agent 生态界定为现代社会技术部署的一个核心要素（与底层大模型、云端算力、API 协议、支付网络与合规护栏并置），本文得以摆脱“AI 会不会取代人”的本质主义之争，转而聚焦于行动条件、摩擦成本与主体形式的动态生成。

## 19.2 文献来源、引用纪律与验通口径

为保证文献证据的可复核性，本文在文献处理与同行竞争者回应上确立了严格的自核纪律。

正如第十四章（§十四）引言与文献验通日志所公开说明的，**本文回应的当代直接竞争者，严格限于其 DOI 或 arXiv 标识符能经公开路由（arXiv API、doi.org、Crossref、OpenAlex 等）解析、且取回题名与所引一致的文献；每条验通记录均包含可重跑的查询 URL、HTTP 状态与取回题名，原文页码未取得者另标待验。白名单外的行业通讯、播客转录、软件仓库与无永久标识符的文本只作背景，不入参考文献，亦不作理论回应（§十四）**。

## 19.3 反身性案例：作为 Agent 辅助写作实验的本文生产

作为一项关于“人—Agent 生态（$H+\mathcal{A}$）”的理论探索，本文自身的生成过程构成了一个反思性的具身实践案例（说明性而非实证性依据）。

### 1. 写作生态的劳动分工与人类保留
本文的起草、论证与校订，是由一位人类作者与一组承担明确功能分工的 Agent（文献调研代理、正文起草代理、对抗性审读代理、术语译校代理及格式排版代理）共同协同完成的。在这一人机协作部署中，人类作者保留了不可让渡的核心理论决断：
- 核心研究问题的提炼与问题化框架设定；
- 批判理论立场的最终裁定（如拒绝技术乌托邦主义、确立同意 Pareto 规范底线）；
- 对各轮对抗审读质疑与多代理分歧的终局裁决。

### 2. 剩余行为的内部证据
在本文的协作实践中，涌现出了一个具有理论反思意义的现象：人类作者在推进写作时，多次主动绕过编排层（领队 Agent）直接向专业 Agent 发起干预，并多次否决与覆盖（override）Agent 提出的修改建议与自动化文本。

这种在自动化协作流中出现的**“绕过编排、主动覆盖（override）、撤回输出与直接介入”**等行为，与本文在导论（§1.7 判据 3）中所列的剩余行为同型，可作为分裂论与元 Agent 论（§五）的一项内部证据；本文只把它记录为案例，不据此作更强的推论。

## 19.4 研究限度声明

本文的研究成果受到以下客观条件的限制，读者在理解本文结论时应予注意：

1. **探索性文献审计的样本限度（前指 §1.6）**：
   在第一章（§1.6）中引用的关于既有 AI 伦理文献“保存性偏向”的初步编码审计（$N=72$），存在两项明确的方法论限度：其一为底层文献表的来源可靠性限度（随机抽检严格命中率为 4/10，存在未能验通条目）；其二为编码方法限度（同源单编码者、非随机目的性抽样且缺乏编码者间一致性检验）。本文将其严格界定为探索性的辅助参考，绝不夸大为定论。
2. **当下史的经验开放性**：
   由于 Agent 技术、平台治理协议与法律规制体系正处于剧烈的早期演进之中，本文所构建的理论框架与三项竞争性情景（§十五）本质上是开放性的假说体系，其最终解释效力有待未来长期的微观社会学田野调查与宏观制度演化予以实证检验。
3. **现状描述的截面时效**：
   §1.8 的现况描述以 2026 年 9 月为截面，一年内可能过时；本文的论证只依赖其定性分界（多 Agent 并存已发生、其协调与法律效力尚未普及），不依赖任何具体数值，也不预测两种未来形态中哪一种胜出。
