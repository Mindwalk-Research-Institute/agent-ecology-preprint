## 工作办公

- Microsoft 365 Copilot（微软）——在 Microsoft 365 各应用中与用户并行处理办公任务。[^a01]
- 飞书智能伙伴 Aily（字节跳动）——围绕大语言模型编排 AI 技能并一键发布到多个渠道，Agent 可调度上百个企业服务连接器与协同套件，流程引擎支持工作流可视化编排。[^a02]
- 企业微信 5.0（腾讯）——根据聊天、文档、表格、会议、邮件等自动总结工作进展；在"工作台—智能机器人"创建机器人用于智能问答，支持 API 模式对接企业自有模型。[^a03]
- Slack AI（Salesforce）——基于组织在 Slack 内的集体知识提供生成式 AI 功能。[^a04]
- Notion AI（Notion Labs）——在 Notion 内搜索、生成、分析与对话。[^a05]
- Gemini for Workspace（谷歌）——把生成式 AI 内置于 Gmail、Docs、Sheets、Slides 与 Meet。[^a06]

## 健康

- 阿福（蚂蚁集团）——免费的健康问答与解读，解读检查报告，医学搜索获取诊疗指南与诊断标准。[^a07]
- Ada Health（Ada Health GmbH）——面向个人的症状评估，帮助用户管理健康。[^a08]
- S.A.R.A.H.（世界卫生组织）——由生成式 AI 驱动的数字健康促进者原型。[^a09]
- 京医千询（京东健康）——据央广网报道，面向医疗健康行业的大模型，设计为与患者和医生对话，落地方案含面向个人的数字医生与健康管家。[^a10]

## 购物、出行与生活

- 淘宝问问（阿里巴巴）——通过问答对话把模糊的购物需求变得明确，对比多个商品并生成选购建议。[^a11]
- Amazon Rufus（亚马逊）——在亚马逊购物应用内以对话方式提供关于商品选择的建议。[^a12]
- TripGenie（携程）——行程规划、航班与酒店推荐和对话式预订。[^a13]
- 小美（美团）——据证券时报报道，以自然语言交互完成外卖下单、餐厅推荐与订座导航。[^a14]
- 小高老师（高德地图）——据人民网报道，以多模态方式与用户交互、调度高德内部工具，主智能体经 MCP 调用子智能体。[^a15]
- 飞猪开放平台（阿里巴巴飞猪）——将机票、酒店、门票等旅行场景向开发者开放（开发者接口）。[^a16]
- 高德开放平台路径规划 Web 服务（高德地图）——提供路径规划的 Web 服务接口（开发者接口）。[^a17]

## 创作与编码

- Cursor（Anysphere）——由 Agent 把想法转为代码，用户可把任务交给它完成。[^a18]
- GitHub Copilot（GitHub / 微软）——在编辑器内建议整行或整个函数。[^a19]
- Claude Code（Anthropic）——读取代码库、编辑文件、运行命令并与开发工具集成。[^a20]
- 剪映（字节跳动）——一站式 AI 成片、AI 图片设计、AI 配音与多轨道编辑。[^a21]
- 即梦 AI（字节跳动）——AI 绘画与 AIGC 视频创作平台。[^a22]

## 通用助手与 Agent 平台

- 豆包（字节跳动）——AI 对话问答助手，兼作写作、文案、翻译、编程工具。[^a23]
- Kimi（月之暗面）——以智能体集群与目标模式并行执行任务的知识工作助手。[^a24]
- 扣子（字节跳动）——基于 Agent 技术集成写作、演示文稿、表格、设计等功能的一站式平台。[^a25]
- GPTs（OpenAI）——用户创建组合了指令、额外知识与技能的定制版 ChatGPT。[^a26]
- Dify（LangGenius）——在一块画布上构建 Agent、知识管线、模型与工具，可云端、私有网络或自托管部署。[^a27]
- FastGPT（Labring）——构建安全、可控的企业级 AI Agent。[^a28]
- 有道智云 AI 开放平台（网易有道）——为政府、企业和开发者提供基础 AI 能力的开放平台。[^a29]

## 协议与编排

- Model Context Protocol（MCP）——把 AI 应用连接到外部系统的开源标准。[^a30]
- AutoGen（微软）——构建 AI Agent 与应用的框架，含单/多 Agent 对话应用的编程框架。[^a31]
- LangGraph（LangChain）——控制 Agent 工作流：持久执行、记忆、流式与人在回路。[^a32]
- CrewAI（CrewAI Inc.）——构建协作式 Agent、团队与流程的框架。[^a33]

## 金融、教育、政务与客服

- Duolingo Max（多邻国）——订阅档位，为学习者提供基于 GPT-4 的新学习功能与练习（教育）。[^a34]
- Zendesk AI Agents（Zendesk）——面向客户服务的 AI Agents 产品（客服）。[^a35]
- 阿里云智能对话机器人（阿里云）——基于通义千问的客服对话大模型，可部署于网站、APP、IM 等入口提供自助咨询，支持上传文档、网页、高频问题与多轮对话流程作为知识源（客服）。[^a36]

## 中国办公与个人 Agent

- 飞书智能伙伴 Aily（字节跳动）——Agent 调度上百个企业服务连接器与飞书协同套件完成任务，流程引擎支持工作流可视化编排（亦见"工作办公"）。[^a02]
- 腾讯 WorkBuddy（腾讯）——开发者把行业 know-how、企业业务系统与服务转化为 WorkBuddy 生态中的标准资产，开发自己的 Buddy 应用，Agent 可直接读写外部系统数据。[^a37]
- 腾讯元宝（腾讯）——面向日常生活与工作场景提供 AI 搜索、总结与写作，解析数十万字长文与含图表的复杂文档。[^a38]
- 腾讯 ima（腾讯）——以知识库为基础的 AI 知识管家，提供"搜—读—写"一站式体验，基于知识库与全网信源问答，可通过技能扩展执行复杂工作流。[^a39]
- 钉钉 AI 助理（钉钉）——跨应用调用审批、考勤、待办、日程等企业系统，把自然语言指令转化为可追踪的业务结果；支持通过录制操作流程或脚本对钉钉内及外部网页做自动化操作。[^a40]
- WPS AI（金山办公）——在文档中按提问精准搜索，辅助复杂数据处理，自动生成公式、统计排名并按条件标识数据。[^a41]
- 豆包工作（字节跳动）——围绕用户设定的目标自主拆解任务并调用工具；在 Windows 环境下操作电脑，自动打开网页、填表、完成跨页面操作；可在一个任务下分派多个子智能体并行执行。[^a42]
- Kimi K3（月之暗面）——以智能体集群与目标模式并行执行任务，生成演示文稿与可玩游戏（亦见"通用助手与 Agent 平台"）。[^a24]
- 通义千问 App（阿里巴巴）——长文档解析与归纳总结，内置智能体频道，可调用垂直领域专家智能体分担复杂工作。[^a43]
- 讯飞星火桌面端（科大讯飞）——上传 Word、PDF 自动摘要与全文解读，会议录音转写与纪要生成，桌面划词与截图提取，常驻侧边栏。[^a44]
- 秘塔 AI 搜索（秘塔科技）——研究模式整合全网信息生成结构化研究报告，自动梳理大纲并以思维导图呈现，可导出为 Word 或 PDF。[^a45]
- AutoGLM / Phone Agent（智谱 AI）——以多模态方式理解手机屏幕并通过自动化操作完成任务，用户以自然语言描述需求，系统解析意图、规划动作并执行整个流程。[^a46]
- Manus（Manus AI）——浏览器操作员围绕自然语言目标自主规划多步操作、浏览网页、分析数据、创建网站与幻灯片并交付最终结果。[^a47]
