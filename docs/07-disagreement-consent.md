# 第七章 分歧、同意 Pareto、消极自由与共同世界

## 7.1 分歧作为政治哲学的起点：被划杠的大他者与制度中立性

在当代关于人工智能与社会治理的哲学讨论中，一种普遍的理论冲动是试图从形而上学或终极本体论出发，直接推导出一套理想的政治制度或对齐法则。然而，在拉康精神分析的严密视域下，现代政治哲学的前提必须奠定在一个不可逆转的结构性事实之上：**象征界的大他者本身是被划杠的（$\bar{A}$），其匮乏本身被一个能指所标记（$S(\bar{A})$）；在结构上不存在大他者的大他者（there is no Other of the Other）**[[Lacan, 2006](refs.md#lacan_ecrits_complete_version)]。

必须首先明确的是，大他者的非完整性并不内嵌任何预设的政治方向性：
$$\bar{A} \;\not\Longrightarrow\; \text{Communism / Liberalism / Revolution / Conservatism}$$

宣称“大他者不存在”，既不能自动推导出自由主义市场秩序的必然性，亦无法为激进革命或威权控制提供本体论辩护。政治哲学的真正问题，恰恰始于这一终极价值保证者的缺席：当社会中并不存在一个先验的、普遍认可的价值真理，而各个异质主体之间又具有不可化约的根本价值分歧时，人类应当如何组织共同行动并做出具有拘束力的集体决定？

欲望的 Agent 化（Agentification of Desire）并没有消除这一根本问题，反而以极高的技术密度将其推向了制度前沿。当个体能够凭借专属的 Agent 生态将私人要求推向现实时，分歧不再仅仅停留在语言观念的争论，而是直接转化为现实网络中异质代理集群之间的策略冲突与资源争夺。

## 7.2 同意 Pareto 与代理政治的剩余：局部规范性及其失效模式

面对形而上学终极价值的退场，一种常见的理论退缩是滑向相对主义的道德虚无，认为在没有绝对真理的前提下任何规范性判断都无从谈起。然而，“缺乏终极价值基础”绝不等于“社会无法进行具体的、情境化的价值评价”。

为了在无终极担保的条件下确立局部的规范性标准，本文拒绝采用新古典福利经济学中预设个体效用函数完备且给定的“偏好 Pareto”（preference Pareto），转而采纳维克塞尔与布坎南公共选择理论传统中的**“同意 Pareto”（consent Pareto）**[[Wicksell, 1958](refs.md#wicksell1958_principle_just); [Buchanan and Tullock, 1962](refs.md#buchanan1960_calculus_consent)]。同意 Pareto 的核心原则是一致同意规则（unanimity rule）：**一项行动或制度安排的影响若不被任何受影响的相关主体所明确反对，则该项行动在此标准下构成一项改进。** 在此，“承认”仅取其弱意义上的当下不反对（consent），而不诉诸黑格尔或霍耐特传统中关于主体间精神确证的强承认范式。同意 Pareto 不依赖外生给定的固定偏好，而仅仅依赖主体在具体情境中所表达的当下意志，因而与偏好的内生演化逻辑保持了严格的结构兼容。

然而，当社会交往步入生态间交互（第四型，inter-ecology interaction）形态时，同意 Pareto 遭遇了一场关键的机制转折——**代理同意 Pareto（proxy-consent Pareto）**。
在跨生态的自动化协商中，“受影响者是否反对”通常不再由人类肉身在具体场景中直接表达，而是由被委托的代理实体根据提示词规则与参数阈值代为声明。此时，代表者（Agent）与被代表者（Subject）之间的结构性缝隙再次浮现：代理所表达的同意，仅仅是对符号化要求的同意；要求之外未被符号化穷尽者作为政治层面的剩余（remainder）被遗留下来，主体的欲望与潜在关切正围绕这一剩余而无处被代表。由此，Pareto 原则不仅没有成为终结政治争议的万能灵药，反而将核心问题从古典的“什么是正义”转移至现代的“谁在代我同意”。

这一机制在实践中展现出两个关键的失效模式：
1. **现状偏向与受影响范围的虚假收缩**：一致同意规则在形式上赋予每个受影响者以否决权；然而在 Agent 社会中，由于个体行动的技术自足性增强，行动者得以在技术上绕过与外部他人的直接协同，从而在形式上缩小了被界定为“受影响者”的社会集合。这导致大量行动看似平凡地满足了同意 Pareto，实质上却是通过技术隔离切断了潜在受影响者的发声渠道。
2. **被生产的同意（Produced Consent）**：当基础模型平台与代理系统深度参与个体要求的生成与偏好塑造时，代理所表达的“同意”本身可能成为平台算法诱导与预筛过滤的技术产物。因此，同意 Pareto 绝不能被神圣化为永恒标准，它只能作为一种局部的、当下的、且原则上必须保持可撤销性的程序检验工具。

## 7.3 消极自由与自足的范畴滑移：伯林内在堡垒的技术化批判

在政治理论话语中，有一种倾向把智能代理对个体行动能力的放大理解为“消极自由”（negative liberty）的技术实现。然而，这种理解混淆了政治自由与生存状态之间的关键范畴界限。


严格按照以赛亚·伯林的原初界定，消极自由指的是行动主体在不受他人故意阻碍或干涉的情况下自主行动的范围[[Berlin, 2002](refs.md#berlin_2002_two_concepts_of_liberty_ch)]。伯林在其经典论述中做出了一个至关重要的警示：**必须严格区分自由本身与行使自由的物质条件（如财富、技术、体力或独立性）**。缺乏行使自由的能力固然令人遗憾，但这属于能力匮乏，而非遭受了他人强加的不自由。

在 Agent 社会的展开中，发生了一场深刻的概念滑移：智能代理所显著提升的，实际上并不是免于制度或他人干涉的消极自由，而是主体的**技术自足（technical self-sufficiency）**——
即个体在实现具体世俗目标时，对特定外部他人的功能性依赖大幅降低（从“请你不要干涉我”滑向“我越来越不需要你”）。本文正是将这种把“自足”误认为“消极自由”的范畴混同作为核心分析对象。

消极自由是制度对外部强制性干涉的合法划界，而原子化则是自足状态引发的社会人际依赖退潮；前者在逻辑上绝不必然导向后者，而 Agent 生态正是将二者勾连起来的历史性技术变量。

更为深刻的是，伯林曾对斯多亚学派与康德主义传统中**“退入内在堡垒”（retreat to the inner citadel）**的自由观提出过严厉批判——值得强调的是，伯林正是把它列为积极自由的一种退化形态（通过主动缩减自身欲望与外部接触来宣称自足），而非消极自由的极端化。当外部现实充满痛苦、阻碍与不可控的他人时，主体往往通过主动缩减自身依赖范围，退居到自我能够完全掌控的内在堡垒之中，并自欺地将这种免于外界骚扰的孤立状态命名为“自由”。Agent 生态所提供的，实质上是一种**技术化扩张了的内在堡垒**；依靠高度可用的代理生态，个体在自己的数字领地内构建起高度定制、自我闭环的行动系统。堡垒的边界虽然被算力拓宽，但它作为对外部世界之防御性收缩的形态并未改变。堡垒的最深处不是自足，而是主体作为对话者的社会退场：他不再需要任何人的承认，也不再被任何人拒绝；其形态与可观察指标见第十五章情景 A“堡垒的内极限”。


如果说贡斯当曾指出现代人的自由在于享受私人独立与和平生活，而贡斯当本人正深刻警告这种独立的危险在于可能因放弃政治参与而招致自由的彻底丧失[[Constant, 1819](refs.md#constant1819_liberty_of_moderns)]；赫希曼曾系统阐释无摩擦的退出（exit）机制往往会侵蚀公共领域中发出呼吁（voice）的动力与必要性[[Hirschman, 1970](refs.md#hirschman1970_exit_voice_loyalty)]；那么 Agent 社会的潜在风险正在于：当退出变得极易实现、技术堡垒变得高度自足时，人类面对真实他者并维系共同生活的能力可能发生萎缩。

## 7.4 程序性政治与共同世界：在无绝对真理处的暂时决断

当社会中的价值冲突不可化约、且无法通过简单的技术隔离予以彻底规避时，共同体的运转依然必须依赖于一系列制度化程序：理性说服、协商与交换、民主程序（投票、抽签）、司法诉讼、退出与分离（exit / separation），乃至最终的强制性裁判。

在此，必须对程序的性质做出关键的认识论区分：
$$\text{决定谁赢} \;\neq\; \text{证明谁正确}$$

在被划杠的大他者（$\bar{A}$）前提下，民主与法治程序的真正哲学尊严，不在于它能够神圣化地揭示某种所谓的“终极真理”，而在于它提供了一种**在不将决断神圣化为真理的前提下做出决定的制度框架（*decision without sacralizing decision as Truth*）**。通过程序做出的裁判仅仅是暂时性平息纷争的行动依据，它绝不剥夺失败方继续保留异议、组织公共讨论并在未来合法程序中逆转决议的权利。

然而，欲望的 Agent 化对这一共同世界构成了深层挑战：如果日常的大量利益摩擦与价值分歧被个体通过代理中介提前过滤、绕开或技术性自足化，人类主体可能逐渐失去在公共领域中直面分歧、忍受争辩、权衡妥协并达成共同决断的实践技艺。一个缺乏真实交往摩擦的社会，可能在获得微观自足的同时，面临维系宏观共同世界的政治能力损耗。

## 7.5 虚无主义作为封闭幻想：肯定性实践与情境化规范判断

最终，本文必须正面回应尼采式的虚无主义挑战。当人们意识到大他者并不存在、任何价值体系都无法获得形而上学的绝对终极奠基时，极易坠入被动的虚无主义，宣称“既然没有终极真理，那么一切皆被允许，一切价值皆属等价”。

本文坚决拒绝这种虚无主义结论。在本文的框架中：

> **虚无主义本质上是一种“封闭的幻想”，它与“不可能性即封闭”是完全同构的幻象。**

虚无主义者之所以感到虚无，是因为他们暗中依然在哀悼那个死去的、全知全能的绝对大他者；他们认定“一旦大他者退场，世界就彻底闭合，任何行动都失去意义”。然而，拉康精神分析与当代哲学重释（如祖潘契奇对拉康伦理学的解读）表明（见 §4.2），大他者的缺席恰恰敞开了可能域。必须强调的是，这一敞开本质上是偶然域的扩张，而扩张本身并不等同于进步（详见 §4.4）。尼采的“强力意志”（will to power）绝不能被庸俗化地曲解为“强者通吃即是正确”；力量可以决定博弈的实际物理结果，却在逻辑上永远无法自动证明自身的规范正当性。

因此，本文的理论立场既不追求先验的形而上学终极奠基，亦绝不接受价值相对主义的虚无泥潭。社会行动始终发生于具体的历史情境之中；同意 Pareto、程序正义与民主决断正是人类在无绝对担保的条件下，立足于具体情境所展开的局部规范性实践。Agent 生态作为要求现实化的工具，未曾终结人类面对分歧的政治处境，却促使我们以一种更加清醒、祛魅且肯定的姿态，在不可消除的差异中持续拓展共同生活的偶然领域。
