# 第二章 核心命题：剩余不能被计划

## 2.1 核心命题的提出：命题及其两重含义

在当代关于控制论、大模型计算能力与社会工程的前沿讨论中，一个反复出现的理论构想是：随着算力规模、情境感知能力与多代理协作系统的突破，人类社会是否能够构建起全知全能的中央协调中枢，实现全局资源的精细调配并对齐人类的所有目标？

本文立足于拉康精神分析、批判政治经济学与技术哲学的交叉视域，对此给出一个根本性的结构性回答，并正式提出全文的核心理论命题：

> **剩余不能被计划（The Remainder Cannot Be Planned）。**
> 要求（demande）被符号化与技术性应答之后依然留存的剩余（remainder），在本体论上无法被任何计算系统、算法中枢或平台机制事先完全分配、规定或穷尽；欲望围绕这一剩余而动，因而同样不能被计划。

必须明确，这一命题包含着两重递进的理论含义，并严格排除了传统的认识论误读：

1. **结构含义（Structural Thesis, $\gamma$）**：**剩余不能被分配，因为剩余本身就是分配行为自身的产物。** 每一次对社会任务的规划、每一次对主体要求的符号编码、每一次由代理系统完成的高保真交付，都在达成既定目标的同时，结构性地生产出未被该次编码所覆盖的剩余。剩余绝不是计划者的疏漏、算法的盲点或暂时未被采集的数据，而是计划与现实化行动必然伴随的本体论效果。
2. **制度含义（Institutional Thesis, $\beta$）**：**剩余超出了既有社会角色与功能分工的识别范围。** 任何试图按照“主体是什么（身份/角色）”来预先派定“主体能做什么（功能/配额）”的制度安排，在结构上都容纳不下这一剩余。人类主体无法被其在社会技术网络中承担的功能性角色所穷尽。

在此，本文**明确排除**了认识论意义上的解释路径（$\alpha$）：即拒绝将该命题理解为“由于人类信息不足或计算能力有限而无法预测未来”。即使假定一个计算中枢拥有无限算力与完全信息，由于 $(\gamma)$ 所揭示的结构必然性，欲望的剩余依然会在每一次交付达成之后顽固地重新显现。

作为制度对照的一个典型例子，现代市场经济以价格机制协调交换，它不要求行动者事先向全社会证明自身要求的道德正当性，而仅以支付能力和自愿契约为检验标准。然而，正如拉康在《第十七期研讨班》中以马克思剩余价值为模型所阐发的“剩余享乐”（plus-de-jouir）[[Lacan, 1969](refs.md#lacan_seminar17_version)]，以及他在 1972 年米兰讲演中诊断的资本主义话语（见 §13.3）所示，市场体系同样仅能处理被货币化、形式化了的有效需求（economic demand）与消费偏好（preferences），
并在无休止的商品流转中持续再生产着未被满足的欲望剩余。

## 2.2 与哈耶克知识问题的分界：从分散知识到本体论不可能性

为了精确确立该命题的哲学地位，必须首先划清本文与20世纪社会主义计算论战中哈耶克经典批评的理论界限[[Hayek, 1945](refs.md#hayek1945_use_of_knowledge)]。

**本文明确不从哈耶克出发；此处引入哈耶克，仅为划清认识论意义上的分散知识问题（$\alpha$）与本文本体论意义上的结构性剩余（$\gamma$）之间的严格界限。**

哈耶克对中央计划经济的著名批判，建立在认识论视域下的**分散知识问题（dispersed knowledge problem）**之上：
- 在哈耶克看来，社会中关于特定时间、地点与个人偏好的知识，具有本质上的主观性、分散性与默会性（tacit knowledge）；
- 中央计划机关在信息论意义上无法及时收集并处理这些海量的局域知识，因而导致计算延迟与资源错配；价格机制则作为去中心化的通信系统实现了高效协调。

然而，如果仅仅停留在哈耶克的知识论视域，那么计划的不可能性便只是一种暂时的、随技术演进而可能被缩减的工程瓶颈。即便假定当代分布式传感器与大数据表征学习能够对海量分散知识进行高效的数字化汇总，中央计划依然无法捕获主体的欲望。

本文所论证的“剩余不能被计划”，建立在**拉康精神分析的本体论不可能性（ontological impossibility）**之上[[Lacan, 2006](refs.md#lacan_ecrits_complete_version)]：
- 假定在思想实验中存在一个拥有完全信息与强大算力的超级计算系统，它依然无法计划主体的欲望；
- 因为人类欲望（desire）在结构上根本不是某种“事先隐藏在大脑内部、等待被算法挖掘的既定知识或静态偏好”；
- 欲望恰恰出现在生物学需求与语言要求之间的断裂处：要求被符号化编码并被技术系统完全应答之后，仍留下不可交付之物，欲望围绕这一剩余组织自身。

换言之，即便计算系统完美执行了主体表达的每一项操作要求并交付了对应产物，主体在直面交付物的瞬间依然会遭遇“我得到了我所要求的，但这依然不是我所欲望的”这一结构性落差。欲望是不可能性的产物，它在每一次现实化之后被重新激发与重新定位（详见 §十二 回路模型）。因此，计划的不可能性根源于**欲望在本体论上拒绝成为一种可被闭环计算的静态客体**。

## 2.3 反身性适用与命题的理论接口

最后，必须申明该命题严密的**反身性（Reflexivity）**：

> **“剩余不能被计划”这一法则，严格且反身性地适用于 Agent 社会自身。**

这一反身适用确立了本文的核心批判立场：**Agent 生态的崛起，绝不意味着人类欲望从一切制度限制中获得了终极“解放”；相反，Agent 生态所改变的，仅仅是剩余出现的位置、现实化摩擦成本与可见性。**

在人—Agent 生态（Human–Agent Ecology，记 $(H+\mathcal{A})$）的协作网络中，要求现实化的摩擦成本大幅下降（$C_{Demande \to R}\downarrow\downarrow$），但这绝不意味着剩余的消亡。相反，不可交付的剩余被精确地重新定位于**平台许可的合规边界（详见 §11.3 与 §十三），以及真实他者的自愿承认之处（详见 §九）**。

在此意义上：

> **第二章（§二）构成了全文关于剩余的一般定理，而第十三章（§十三）关于平台协议与新的计划性的分析，正是该定理在 Agent 社会平台控制层面的具体应用。**

第十三章将系统分析，集中于少数提供商的平台层如何可能通过模型系统对齐、安全护栏与协议准入形成一种新的计划性，而这一新的计划性同样必然在其边缘持续生产出无法被收编的实在界剩余。


最后，这一法则亦反身性地提示了本文理论构建自身的有限性：本文对 Agent 社会动力学的推演本身亦是一项象征界的符号化实践，真实历史的演化必然会溢出既有的概念框架，在技术与社会的未决碰撞中持续展现出不可预先规划的现实剩余。
