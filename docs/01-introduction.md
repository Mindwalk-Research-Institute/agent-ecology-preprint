# 第一章 导论与问题化：为什么需要一种非保存主义的 Agent 社会理论

## 1.1 现存主体规范基线与保存性构想

在当代关于人工智能伦理（AI ethics）、自主性（autonomy）、价值对齐（alignment）、有意义的人类控制（meaningful human control）以及人工智能中介通信（AI-mediated communication）的广泛讨论中，一个普遍存在但往往未被言明的理论前提是：将当前历史阶段的人类主体形态（记为 $H_0$）设定为不言自明的规范基线。

在此类研究视域中，技术变迁被形式化为一个单向的因果序列：
$$H_0 \xrightarrow{\quad \text{Agent / AI} \quad} H_1$$

随后，研究者们普遍以 $H_0$ 的固有特质为尺度，审视并评估主体性在各个维度上可能遭受的侵蚀与损失：个体的自主决断能力是否被算法推荐所削弱？隐私边界是否在全面感知中坍塌？人类对系统的控制权是否流失？人际交往的真实性与深度是否被合成文本所稀释？以及劳动者的专业技能是否被自动化系统全面贬值[[Floridi et al., 2018](refs.md#floridi2018_ai4people); [Gabriel, 2020](refs.md#gabriel2020_artificial_intelligence)]。

上述提问方式的核心关切，可以高度概括为一个防御性的经典问题：
$$\text{“人工智能将从人类身上剥夺什么？”（What will AI take away from humans?）}$$

必须明确指出，这种以防御风险为导向的研究路径不仅具有现实紧迫性，而且构成了技术治理不可或缺的制度基石。然而，本文在理论层面上提出的批判在于：当理论家将特定历史阶段的主体形态 $H_0$ 固化为先验的规范常量时，其分析框架往往能够极其敏锐地识别技术变迁所带来的“损失”（loss），却在结构上难以概念化、解释并推演技术演进所催生出的**新的行动能力、新型依赖关系以及尚未被既有范畴所覆盖的实践空间**。

本文将这种将既有主体形态视为衡量尺度的理论倾向，定义为**人类主体性的保存性构想（preservative conception of human agency）**。

## 1.2 福柯式反转与技术部署（Dispositif）的当下史描述

为了突破保存性构想的理论盲区，必须在主体哲学与社会理论维度引入福柯式的方法论反转。

在福柯式的主体化分析视域下，人类的主体形态从来不是某种超历史的先验本质，而是在特定技术、制度与权力网络中持续生成的历史产物：
$$H_0 \longrightarrow H_1 \longrightarrow H_2 \longrightarrow \cdots$$

在这一演进序列中，没有任何一个具体形态 $H_t$ 仅仅因为其“恰好是当下的存在形态”而天然享有永恒的规范优先权。因此，本文确立的第一重方法论反转（methodological inversion），即是从**保存性视角**转向**生成与转化视角**：
$$\text{从 Preservation（} H_0 \rightarrow \text{What might be lost?）} \quad \Longrightarrow \quad \text{转向 Transformation（} H_0 \rightarrow H_1 \rightarrow \text{What becomes possible?）}$$

必须坚决强调的是，**这种向 Transformation 的转向绝非对技术进步主义（techno-progressivism）的背书**。本文既不预设新主体形态相对于旧形态的形而上学优越性（$H_1 > H_0$），亦不采纳任何走向技术极权或宿命论的技术悲观叙事（$H_1 < H_0$）。

本文的研究任务，在于严谨地刻画主体**可能域（possibility space，即 $P(H_t)$ 的可能性空间）的变化**：
$$P(H_0) \longrightarrow P(H_1)$$

并且在分析的每一个环节坚守结构一致性：**可能域的每一次扩张，都必然在另一侧生产出新型的不可能性与结构性限制**——包括平台对齐规则的事前预筛、真实他者（concrete others）自愿承认的不可交付性，以及无法被计算系统闭环消解的欲望剩余。

在方法论定位上，本文拒绝将 Agent 的兴起草率地宣称为某种“新认识型（episteme）的诞生”，因为根据福柯知识考古学的严格定义，认识型只能在历史断裂发生之后被事后重构，且绝不能被还原为单一的技术因果决定论[[Foucault, 1969](refs.md#foucault1969_archaeology_knowledge)]。相反，本文将 Agent 生态界定为一个**正在浮现的“部署”（dispositif）的核心要素**——它与云端算力平台、密码学身份协议、支付清算网络以及合规审查机制共同交织，构成了一个新型的社会技术装置[[Foucault, 1980](refs.md#foucault1980_power_knowledge)]。本文的目标，正是对这一正在形成的现实化部署展开严谨的**当下史描述（history of the present）**。


## 1.3 从“AI 会对人做什么”转向“人经由 Agent 能做什么”

基于上述方法论反转，本文在导论中明确确立分析视角的根本位移：

> **本文不再追问“在人工智能接管了诸多能力之后，人类最终还剩下什么独特本质”，而是深入探究“Agent 部署（agentic dispositif）使哪些先前受制于资源与组织摩擦而无法付诸实践的主体化行动成为可能”。**
> *(Rather than asking what remains uniquely human after AI, this paper asks what becomes newly possible for humans through agentic AI.)*

必须声明，这种侧重于“人经由技术能做什么”的能力式问题化路径，其问法接近贝尔纳·斯蒂格勒（Bernard Stiegler）关于技术个体化（technological individuation）的批判哲学进路[[Stiegler, 1994](refs.md#stiegler1994_technics_time_1)]；但本文不采纳其技术药理学的整体哲学框架，理论核心依然立足于拉康精神分析与福柯主体化分析的分层结合（详见 §1.2）。

由此，本文明确拒绝加入寻找“AI 永远无法取代的人类最后堡垒”的技能防御战，理论构建无需依赖于证明某种排他性的先验断言（$\exists X, \text{Human can } X \land \text{AI cannot } X$）。进而，面对核心理论难题——**“当 Agent 可以承担执行、协调、组织乃至创建其他 Agent 时，人还在社会行动中做什么？”**（详见 §十）——本文提出**人类主体性的生成性构想（generative conception of human agency）**：
- 聚焦于新型社会技术结构如何重塑可行动之目标的生成机制；
- 剖析私人要求转化为现实行动的摩擦成本变迁（$C_{Demande \to R}$）；
- 考察个体无需依附于庞大科层组织即可调用的组织能力；
- 阐明主体与特定他人之间依赖关系的重构；
- 以及推演新主体形式在与技术系统和真实他者碰撞中生成的结构性条件。

## 1.4 Agent 相对于货币、市场与互联网的特异性

在提出上述框架时，一个必然遭遇的理论质疑是：如果将本文论证中的“Agent”替换为货币、市场或互联网，相关命题是否依然成立？换言之，Agent 作为一种社会技术中介，究竟具有怎样的**特异性（specificity）**？

本文指出，先前的人类媒介与制度发明（如货币制度、市场交换网络与互联网通信），虽然极大降低了资源流通与信息传递的成本，但在其运作机制中**始终严格保留了某一位人类他人的否决权（其中前三类还要求该他人是特定的）**：
- 货币的流通，必须以特定交易对手愿意接受为前提（齐美尔在《货币哲学》中阐明了货币如何将人身依赖转变为非人身依赖，但交易仍需对手方的自愿交换）[[Simmel, 1900](refs.md#simmel1900_philosophy_of_money)]；
- 互联网的信息扩散，必须以接收端特定主体的注意力响应与互动确认为前提；
- 传统协作网络的建立，必须以特定合伙人、雇员或投资者的加入同意为前提（正如交易成本理论与点对点协作理论所指出的）[[Coase, 1937](refs.md#coase1937_nature_firm); [Benkler, 2006](refs.md#benkler2006_wealth_networks)]。
- 外包、众包与零工平台的匹配，虽已把“必须是某一位特定他人”放宽为“任一愿意接受的他人”，但其成立仍以某一位人类对手方的实际接受为前提，且匹配本身仍需承担搜寻、议价与履约的协调成本[[Benkler, 2006](refs.md#benkler2006_wealth_networks)]。

相比之下，在上述媒介序列中，Agent 是第一种使个体的“组织与协商能力”无需经由任何人类他人（无论特定他人还是任一可替代的他人）的预先同意即可获得规模扩张的基础设施。这一特异性建立在两项核心机制之上：
1. **组织与协商劳动的实体性吸收**：Agent 不仅仅像电报或互联网那样传递通信内容，而是作为具备推理与工具调用能力的执行实体，直接接管了过去必须依赖庞大人际团队才能完成的编写、审查、设计、排期与跨主体协议协商劳动本身；
2. **主动提出目标的中介身份**：Agent 不仅仅是被动的管道或工具，而是能够主动进行反思推荐、意图推断并生成候选目标的能动实体。它以“说话者”而非“纯渠道”的身份深度切入要求形成的动力学回路，因而同时作为要求的执行者与新能指的生产者而运作。

在此必须指出，本文的反馈回路模型充分承认哈金（Ian Hacking）的“循环效应”（looping effects）、卡隆与麦肯齐（Callon & MacKenzie）的“操演性”（performativity）以及行动者网络理论（ANT）和分布式认知为其先行理论版本[[Callon, 1998](refs.md#callon1998_markets_embeddedness); [MacKenzie, 2006](refs.md#mackenzie2006_engine_not_camera); [Hacking, 1995](refs.md#hacking1995_looping_effects)]；本文的理论差异不在于形式上的“回环互动”，而在于由上述两项特异性机制所驱动的深层动力学（详见 §14.7）。

必须在此作出两项明确的收缩限定：
- 第一，在物理世界的物质改造与资源实体交付层面，行动依然必须经由外部环境与他人的物理配合；
- 第二，**这种“不经由任何人类他人同意”绝非绝对无条件的自足，它依然必须经由底层基础模型与云端平台的对齐规则与服务许可——平台在此成为了新的、高度集中的中介他者（详见 §11.3 与 §十三）**。

## 1.5 新颖性声明与统一理论链条

本文的理论新颖性（novelty claim），绝不建立在宣称“本文在真空中首次发明了某个孤立概念”之上。截至 2026 年 9 月，在已检索的学术与公开思想材料中，学者们已分别就算法治理术、主体化、人机中介通信、多智能体协同、个人代理自主性、偏好内生性以及拉康精神分析与人工智能的结合展开了富有成效的探索。

本文的核心贡献在于：**将这些在各自分支学科中相互割裂的研究传统，系统汇合为一个以智能体生态（本文以下称 Agent 生态，Agent ecology）为行动基础设施、以要求的现实化与剩余的再生产为核心动力学的统一社会理论模型。**

这一统一模型的完整动力学链条如下：
$$\text{Dispositif} \longrightarrow \text{Subjectivation} \longrightarrow \text{Desire} \longrightarrow \text{Demande} \longrightarrow \text{Goal} \longrightarrow \text{Agent Ecology} \longrightarrow \text{Action} \longrightarrow \text{Reality} \longrightarrow \text{Remainder}$$

并进而形成微观与宏观交织的演化反馈回路：
$$rest_t \longrightarrow \text{Social Environment}_{t+1} \longrightarrow \text{Subjectivation}_{t+1} \longrightarrow \text{Desire}_{t+1}$$

在这一链条中，Agent 生态接管了从要求向现实的执行跨越，而实在界的不可消除之剩余（remainder）则被持续生产并在新的结构位置显化，成为驱动下一轮主体变化与欲望重塑的内在动能。

## 1.6 “保存性偏向”的证据尺度与方法论限度

为了初步评估当代学术界在审视人工智能与主体性时是否存在系统的“保存性偏向”，本文参考了一项覆盖 9 个人工智能相关交叉学科领域的探索性文献编码审计（文献样本量 $N=72$）。

该审计将现有研究对主体性的审视取向编码为三类：保存性构想（Preservative, P）、转化性构想（Transformative, T）与生成性构想（Generative, G）。在纯类别样本（$N=64$）中，其分布比例呈现为：
$$\text{P : T : G} = 42.2\% : 29.7\% : 28.1\%$$
且在被归类为转化性（T）的研究中，超过 80% 的论述依然深嵌在以既有主体为参照的防御性风险框架之内。

**必须以严格的学术诚实态度并列写明该项审计的两项实质性限度：**
1. **底层文献来源的可靠性限度**：该审计所依据的文献基础在抽样复核中，严格核实命中率为 4/10（含一条 arXiv 编号解析到无关论文、一条 DOI 404），其引证文献包含尚未被全面验通的探索性条目；
2. **编码方法学的局限性**：该审计采用同源单编码者的非随机目的性抽样，且未进行跨编码者的一致性检验（inter-coder reliability test）。

因此，本文将上述审计结果严格定性为“一项具有方法论限度的探索性线索”，用以辅助说明该框架在所检样本中的分布倾向，而绝不将其夸大为已获实证确证的终极定论。

## 1.7 研究问题、中心论点与三项可证伪判据

### 1. 五项核心研究问题
为了系统推演上述理论链条，本文设定并回答以下五个紧密咬合的研究问题：
- **RQ1（行动单元）**：社会行动单元是否正在从孤立的“个人”转变为“Human + Agent Ecology”？（必须明确约束：$H+\mathcal{A}$ 是**行动单元而非身份单元**，生态是主体分裂展开的技术场域而非封闭外壳，详见 §五）；
- **RQ2（剩余移动）**：当要求的执行被 Agent 接管后，不可消除的剩余在社会结构中的出现位置如何移动？（详见 §十）；
- **RQ3（摩擦成本）**：Agent 是否显著降低了“要求 $\to$ 现实”的摩擦成本？（$C_{Demande \to R}$ 实际测量的是要求而非欲望的现实化成本，详见 §十一）；
- **RQ4（社会形态）**：功能性人际互动减少后，社会走向何种“原子化”？（本文预测为：人际互动总量下降，非工具性互动占比可能相对上升，作为三种竞争假说之一，详见 §六 与 §十五）；
- **RQ5（欲望回路）**：Agent 是要求的单向执行器，还是通过剩余参与生产新的欲望？（详见 §十二）。

### 2. 全文中心论点（统一核心句）

> **Agent 社会的特异性，不在于它中介了人与人的关系，而在于它把“拓展个体可能域边界”这一活动的成本，从需要集体授权或特定他人同意的规模，降到个体可承担的规模。这构成一个新的现实化部署（dispositif）：其中要求的执行几乎自动化，先前不被写下者大量开始被写下，而实在界作为不可交付的剩余重新定位，首先定位于平台许可的边界与他者的承认之处。**
>
> *(简洁版：Agent 使要求的执行近乎自动化，因而使欲望的剩余更快、更并发、更可见地重新出现。)*

本文将这一由行动基础设施重塑所驱动的社会精神动力学演变过程，正式命名为**“欲望的 Agent 化”（Agentification of Desire）**。必须在此强调，该命名中的“欲望”严格承袭拉康精神分析对要求（demande）与欲望（desire）的发生学切割——智能代理直接中介与自动化执行的永远只是可形式化编码的要求；欲望经由要求被表达却不被要求穷尽，它围绕要求被应答后留下的剩余重新定位，并由此持续展开其动力学回路（详见 §三 与 §十二）。

### 3. 三项可证伪判据

为了使本文所构建的理论框架具备严谨的科学反思性与经验可检验性，本文在导论中明确设立**三项可证伪判据**（逐字承诺）：

本文称“分裂论”者，指：主体的结构性分裂（$\bar{S}$，§三）不因 Agent 生态的编排整合而消失，反在多代理并发中被外部化与显化（§5.2）。

1. **若观察不到“先前需要集体授权或特定他人同意的事务，迁移为个体可直接行动的事务”，本文的核心命题错。**
2. **若功能性人际互动未上升，且非工具性人际互动的占比不上升，则情景 B 错；其中若两类互动的绝对量同步显著下降，则情景 A 对；若功能性人际互动显著上升，则判别转入情景 C。**
3. **若编排层能消除 Agent 间冲突，且主体不再出现覆盖、撤回、直接介入、目标快速更替等剩余行为，则分裂论错。**
   附则：若四种剩余行为缺席的同时要求频率上升，这不是分裂论的反证，而是情景 A 内极限的标记（§十五）；分裂论的反证要求四种行为缺席且要求频率不上升。
   附则二：判据 3 在缺席方向承担证伪功能。四种剩余行为的出现，可与执行偏差、外生约束变动、新信息到达等认识论层（§2.1 的 $\alpha$）原因并存，本文不据其出现作肯定式推论（§19.3 的内部证据同此口径）。

## 1.8 现状与趋势：本文论证所依赖的经验基线

本文的论证对象是趋势的结构后果，而非现况的描述。本节分三层：现况是写作时可观察的人—Agent 使用形态，趋势是其中可辨认的方向，结构后果是后文推演的部分；现况只是趋势的早期形态。写法上，现况句现在时并引证，趋势句用"正在"并引证，结构后果句用可能句。产品清单见附录 A。

**个体层。** 同一个人已在不同场合使用不同的 Agent：用豆包工作让 Agent 在电脑上开网页、填表、跨页面操作[^s38-22]，用淘宝问问购物[^s38-15]，用蚂蚁的阿福问诊[^s38-21]，用 Claude Code 写代码[^s38-4]——四个 Agent 来自四家供应商，互不知晓彼此，冲突由人调和。多 Agent 并存且互不协调因此是现况而非预测，证据即上述产品；一项十人日记法质性研究表明并用已带来协调负担[[Pyo et al., 2026](refs.md#pyo2026_one_is_not_enough)]，此即第五章"同时性"机制的起点。采用分层：据中国互联网络信息中心的生成式人工智能应用发展报告与互联网发展状况统计报告，使用深度随年龄、职业与地区而异[[{中国互联网络信息中心}, 2025](refs.md#cnnic2025_genai_application); [{中国互联网络信息中心}, 2026](refs.md#cnnic2026_57th_statistical_report)]；据欧盟统计局的企业调查，企业用 AI 随规模分层[[{Eurostat}, 2025](refs.md#eurostat2025_ai_enterprises)]；据 Anthropic 对其产品使用的分析，整体委托的用法占比可观[[Appel et al., 2025](refs.md#appel2025_uneven_ai_adoption)]。因此第五章的多元性判据只部分成立：Agent 多处理信息与内容任务，需法律效力的支付、签约与身份认证仍以人为主——这就是趋势与现况的分界。

**组织层。** 企业侧有三类：嵌入既有软件的助手、内部工作流 Agent、对外交易或谈判 Agent（早期）；平台侧提供 Agent 的构建与分发入口，平台条款与法规都已把事前审查制度化——第十一章的平台预筛不是预测[^s38-24][^s38-25]。一例是飞书智能伙伴 Aily：企业围绕大模型编排 AI 技能并多渠道发布，其 Agent 调度上百个企业服务连接器完成任务[^s38-19]。

**基础设施层。** 工具调用与 Agent 间通信已有公开协议，如 Model Context Protocol（MCP），把 AI 应用连接到外部系统的开源标准[^s38-8]；这是第六章第三、四型拓扑可被观察的技术前提。编排框架在开发者社区大量存在，面向个体的编排层尚不普及，Agent 市场仍在试验；第十三章的成本迁移在现况中只有雏形。

**两种未来形态假说。** 现况可能走向两种形态或其混合。其一是服务侧 Agent 化：应用本身成为 Agent，Agent 属于平台，剩余首先出现在平台许可的边界；据人民网报道，高德"小高老师"以多模态交互并经 MCP 调用子智能体，是一例[^s38-17]。其二是主体侧 Agent 化：个人建立不同 Agent 参与各类项目，Agent 属于主体，剩余更多出现在 Agent 间的摩擦处；Manus 的浏览器操作员按个人的自然语言目标自主规划多步操作并交付，是一例[^s38-23]。本文命题——进入编码与被交付的始终是要求，欲望围绕其剩余重新定位——对两种形态都成立，不预测胜负；现实大概率混合，是三情景之外的另一维度，不单立情景。

**分界表。**

| 维度 | 现况（已可观察） | 趋势（两种形态） | 本文推演的结构后果 |
|---|---|---|---|
| 行动单元 | 多 Agent 并存、互不协调 | (i) 应用即 Agent；(ii) 个人建立多个 Agent | 人—Agent 生态为行动单元（§五） |
| 交往拓扑 | 第二型普遍，第三型局部 | (i) 平台间 Agent 交互；(ii) 个人 Agent 间交互 | 第四型与双层社会（§六） |
| 要求现实化成本 | 信息与内容任务的摩擦已下降 | (i) 平台内标准化要求；(ii) 跨平台编排 | $C_{Demande \to R}$ 的结构性下降（§十一） |
| 预筛与剩余位置 | 服务条款已在审查 | (i) 许可边界；(ii) Agent 间摩擦 | 剩余首先定位于许可边界与他者承认（§十、§十一） |

本节以 2026 年 9 月为截面；论证只依赖一条定性分界——多 Agent 并存已发生，其协调与法律效力尚未普及——不依赖具体数值。
