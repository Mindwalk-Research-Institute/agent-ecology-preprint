# 第五章 从“一个 Agent”转向 Agent Ecology

## 5.1 反对数字人格总代理：社会能指与多元性判据

自个人计算与早期智能代理理论萌芽以来，技术话语与社会想象中长期占据主导地位的，是一种“一人一代理”的单一人格总代理模型。无论是在早期人机界面理论中被具象化为全能型“数字管家”（digital butler）的构想[[Negroponte, 1995](refs.md#negroponte1995_being_digital)]，还是在当代大语言模型普及初期被广泛讨论的“个人数字分身”（digital twin），这种观念都隐含地预设了一个未经反思的规范基线：人类主体是一个具有内在统一性、偏好完备且无内部根本冲突的理性个体；相应地，作为其技术延伸的智能代理，其理想形态便是一个能够全盘代表该主体偏好、统揽所有日常事务的单一代理实体。

多元性首先是一个既成事实：同一个人已在不同场合使用互不协调的多个 Agent（§1.8）；本节的判据建立在这一事实之上。无论从主体在社会结构中的实际存在方式，还是从当下正在形成的自主代理部署（dispositif）来看，这一“单一人格总代理”模型都难以成立，缺乏结构依据。在社会现实中，人从未作为一个铁板一块的单一身份存在；相反，个体始终栖居于多重制度、角色与社会关系的交叉节点上。因此，人类与自主智能系统的结合方式，并非简单的 $H \leftrightarrow A$（单一人对单一代理），而是正在演化为由大量异质性、专用化乃至情境化代理所构成的生态系统（现况见 §1.8）：
$$H \longleftrightarrow \mathcal{A} \quad \text{其中} \quad \mathcal{A} = \{A_1, A_2, \dots, A_n\}$$

在此，界定这一生态系统之多元性的标准必须得到严格澄清。相关的多元性绝非仅仅指涉计算系统底层包含多少并发的软件子进程或微服务线程，而在于其在社会象征界中所占据的位置。本文提出如下**多元性判据**：

> **凡需要人的身份在场之处，皆有 Agent 代表之。**

主体在结构上是被能指所代表的主体，而历史上被哪些具体的能指所代表则随具体的部署（dispositif）而变[[Lacan, 2006](refs.md#lacan_ecrits_complete_version)]。一个人作为纳税人、投资者、学者、雇员、患者、旅行者、消费者或家庭成员，在不同的社会子系统中所动用的规范逻辑、交往策略与行为目标具有高度的不可还原性。当代多代理框架（如 MetaGPT、AutoGen、Internet of Agents 等）的发展表明[[Hong et al., 2023](refs.md#hong2023_metagpt_meta); [Wu et al., 2023](refs.md#wu2023_autogen); [Chen et al., 2024](refs.md#chen2024_internet_agents)]，多代理工程在实践中普遍采用专业化分工、角色定义以及提示词约束下多个异质代理协同协作的架构。个体通过动态实例化数十、数百乃至数千个短期或长期的专用代理——例如负责投资组合风控的财务代理、追踪前沿文献的研究代理、处理跨时区商务沟通的排期代理、采购生活物资的供应链代理、处理法律合同初审的法务代理，以及临时为某项突发事务生成的专门任务代理——将自身嵌入到复杂的社会网络中。

因此，Agent 生态并非主体的某种外在装饰，而是个体在象征界中行动能力的分布式外延。在此，社会行动的基本单元发生位移：它不再是赤裸的生物学个体，亦非单一的数字替身，而是行动单元意义上的 $H + \mathcal{A}$。必须强调：这是行动单元而非身份单元；生态不是主体的封闭外壳，而是主体分裂得以展开的场域（详见 5.2）。

## 5.2 Agent 之间的矛盾与同时性：主体分裂的外部化技术机制

经典社会理论中的角色冲突理论（如齐美尔关于社会圈交叉的洞见，以及默顿与古德的角色冲突分析）早已指出，个体在不同外部角色结构中承担着相互冲突的规范期待。Agent 生态的新颖之处不在于外部化本身，而在于它通过一种独特的技术机制，将这种冲突推到了同一个并发的操作平面上。
在这一生态中，隶属于同一个体的不同代理之间并非预设地处于无缝和谐的协调状态，相反，它们往往直接承载着主体在不同生活领域中提出的相互矛盾的要求（demande）：

$$\begin{aligned}
A_{\text{investment}} &: \text{“严格压缩非必要开支，执行长期储蓄与套期保值”} \\
A_{\text{travel}} &: \text{“锁定最高规格航旅服务，追求即刻的沉浸式度假体验”} \\
A_{\text{health}} &: \text{“强制执行夜间断网与生理节律监测，规避一切过劳损耗”} \\
A_{\text{research}} &: \text{“通宵抓取与检索跨学科数据库，穷尽未解决学术线索”}
\end{aligned}$$

古典功利主义或主流强化学习对这种多目标现象的标准处理方案，是假设存在一个更高阶的全局效用函数（utility function），通过赋予权重或拉格朗日乘子将其折算为一个单一的优化问题。然而，这种折算无法表达主体欲望的结构性特质。在拉康精神分析的视域下，人类主体从根本上是被能指切开的、未完成的被划杠主体（$\bar{S}$）[[Lacan, 2006](refs.md#lacan_ecrits_complete_version)]。主体向他者提出的要求（demande）从来不是透明且自洽的偏好列表，而是分裂的、情境化的、向他者发出的诉求。

多代理生态之所以在社会哲学层面构成关键节点，在于它通过一种独特的现象学机制——**以并发的同时性（simultaneity）打破了肉身经验的序列性（sequentiality）**——使主体的内在分裂以并发而非序列的方式暴露于现实之中。

在单一生物学肉身的生存条件下，主体的行动在物理时间中被严格限制为线性的序列展开。由于肉身不能同时出现在度假海滩与学术实验室，时间的先后流逝（“先工作后度假”、“白天克制消费夜间冲动网购”）便成为一种天然的遮蔽。时间之维将相互矛盾的要求隐藏在“先后”的掩体之中，使个体得以维持一种想象性的统一自我（ego）。

然而，Agent 生态打破了这种时间的遮蔽。当个体为其异质代理下达目标后，这些代理在数字与物理网络中展开的是完全并发的执行过程。在同一个时间切片内，$A_{\text{investment}}$ 正在自动化清仓高风险资产以规避波动，而 $A_{\text{travel}}$ 正在并发调用支付接口锁定昂贵订金；$A_{\text{health}}$ 发出警报切断系统连接，而 $A_{\text{research}}$ 正在向计算集群提交大规模并发任务。时间的缓冲被抽离，主体内部相互否定的诉求被从主观内省的幽暗角落中剥离出来，直接投影在同一客观现实平面上。主体遭遇的不再是抽象的心理纠结，而是自己的各项要求在现实资源（算力、账户余额、物理排期、信用额度）争夺中发生的彼此否定与相互踩踏。

在此必须做出严格的理论界定：**绝不能将每个单独的 Agent 庸俗化地等同于一个独立的“无意识欲望”**。Agent 作为计算程序与语言模型的产物，其接收并执行的只能是通过自然语言或程序接口被形式化、符号化了的“要求”（demande）与操作目标（goal）。拉康意义上的欲望（desire）绝不等于这些具体的任务指令；相反，欲望恰恰出现在需求与要求之间的缝隙中，围绕要求被技术性应答之后留下的不可交付之剩余（remainder）而动[[Lacan, 2006](refs.md#lacan_ecrits_complete_version)]。

因此，Agent 生态的实质在于：它并非欲望本身的直接化身，而是**主体分裂在技术系统中的外部化展开装置**。它使主体不得不直面自己被符号化要求所撕裂的客观图景。

## 5.3 编排层的任务尺度与去中心化特征

面对生态内部多代理之间的冲突与资源竞争，当代技术系统普遍引入了元 Agent（meta-agent）或编排层（orchestration layer）来进行任务分解、路由调度与冲突仲裁。然而，这一编排层的存在并不意味着“单一人格总代理”在更高层级上的复活。

从系统架构与社会行动的本质来看，**Agent 生态的编排层始终是任务尺度（task-scale）的，而非人尺度（person-scale）的**。

所谓任务尺度，是指编排机制仅在特定项目、特定事件或特定问题域中被临时性、局部性地激活。例如，在完成一项跨国学术会议的组织工作时，一个会议编排元 Agent 可能会动态创建日程代理、差旅代理、论文评审代理与联络代理，并在它们之间进行冲突仲裁与资源调度。但一旦该项任务终结，这一特定的编排结构即告解体。它既不统摄个体的全部生存活动，亦不构成涵盖个体所有社会身份的仲裁法则。

更为关键的是，作为生物复合体核心的人类主体（$H$），拥有在任何时刻随时**绕过（bypass）**、重组或解散编排层的自主行动能力。在实际的人机协同实践中，个体随时可以越过统筹层级的元 Agent，直接向底层某个特定的专业代理发出越权指令，甚至直接引入新的外部代理来推翻先前的编排逻辑。
本文的写作过程即为一例：作者多次绕过领队，直接与审读 Agent 对话并推翻其建议（详见方法说明）。

因此，现有的技术实践（§1.8 基础设施层）与结构逻辑并不支持一个“全知全能的超级代理中枢”的假设。Agent 生态呈现出的是一种高度流动的、分布式与临时性的多中心拓扑结构。本文对编排层的未来商业模式与平台市场结构保持严谨的理论克制，不对具体的产业形态做确定性预言。在本文的框架内可以说：无论编排层如何配置，要求被应答后的剩余在结构上始终是不可交付的；编排层的任务尺度与可绕过性所做的，是使这一剩余在 Agent 社会中保持可见，而不被一个想象性的统一界面所遮蔽。
