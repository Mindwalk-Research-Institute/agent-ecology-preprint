# 第六章 Human–Agent–Agent–Human：社会关系的结构变化与功能性脱媒

## 6.1 从直接人际关系到跨生态交互：社会拓扑的四种结构类型

长期以来，社会学与传播学对人际互动的理解，主要建立在以生物学肉身为物理锚点的交往范式之上。即使互联网与社交媒体的普及彻底重构了交往的时空尺度，技术媒介在很大程度上仍被视为传递人类符号信息的“被动传输管道”。然而，随着具备自主规划、工具调用与多步决策能力的 Agent 生态正在嵌入社会生活（现况见 §1.8），人与人之间的交往拓扑正在演进。这一拓扑结构可以形式化地归纳为四种类型（它们在现实中可部分共存；截至写作时，第二型已普遍，第三型局部可观察，第四型仍是趋势）：

1. **直接人际交往**：
   $$H_1 \longleftrightarrow H_2$$
   在此古典类型中，人类主体之间的符号交换、情感表达与事务协调依赖生物个体的直接肉身接触或同步通讯，交往摩擦与协调成本主要由当事人直接承担。
2. **共享代理/平台中介**：
   $$H_1 \longleftrightarrow A \longleftrightarrow H_2$$
   早期“人工智能中介传播”（AI-mediated Communication, AI-MC）文献所主要关注的即是这一结构[[Hancock et al., 2020](refs.md#hancock2020_ai_mc)]。在此阶段，中心化的算法系统（如智能推荐引擎、邮件智能回复或协同过滤系统）作为一个公共中介，对人类发送与接收的信息进行润色、排序或过滤。然而，该中介通常是单一且中心化的，并不代表特定个体的独立委托意志。
3. **点对点代理协商**：
   $$H_1 \longleftrightarrow A_1 \longleftrightarrow A_2 \longleftrightarrow H_2$$
   随着个人代理的出现，交往双方各自部署了代表自身利益的专用代理实体。人机通信的研究视野由此扩展至代理间的自动化博弈与协议协商[[Liu, 2026](refs.md#liu2026_sovereignnegotiation_bench)]。在此阶段，代理开始作为被委托的“要求执行者”，在人类设定的参数范围内展开跨主体的协议协商与信息置换。
4. **生态间交互（Inter-Ecology Interaction）**：
   $$(H_1 + \mathcal{A}_1) \longleftrightarrow (H_2 + \mathcal{A}_2)$$
   这构成了本文所聚焦的完整形态。在此结构中，社会交往不再发生在孤立的个人之间，亦非发生在两个单一的“数字替身”之间，而是发生在两个高度分化、动态生成的 Agent 生态之间。
$H_1$ 的投资代理、排期代理与法务代理，在数字网络中并发地与 $H_2$ 乃至多个他者的对应代理集群进行协议握手、资源清算与数据互换。

这一拓扑跃迁表明，传统人际关系中由人类肉身直接承受的符号互动，正在被重构为一种多层级的社会技术网络。

## 6.2 被接管的首先是功能性人际关系：交往的工具性抽离

在关于人工智能对人类社会关系冲击的讨论中，一种常见的道德焦虑往往聚焦于“人际情感的异化”或“机器对爱情与友谊的替代”。然而，从社会行动的实际发生机制来看，Agent 生态在社会结构中所引发的变迁，并非首先发生在高度情感化、非功利性的亲密关系领域，而是发生在大规模的**功能性人际关系（functional human-to-human relations）**之中。

所谓功能性人际关系，是指人类主体为了达成某种具体的世俗目的、生产目标或事务性合作而建立的工具性交往纽带。这类交往构成了日常工作与社会组织的很大一部分：
- 商务日程的比对与跨时区排期确认；
- 供应链上的多方询价、比价与履约跟踪；
- 商业合同与法律条款的逐条推敲、修改与草签；
- 跨部门项目中的进度同步、状态汇报与文件格式转译；
- 组织层级中的工作分工派发、工时统计与常规行政审批；
- 标准化物资的采购审批、发票核销与账期清算；
- 合作过程中的常规争议调解与程序性妥协。

在传统社会中，由于缺乏能够自主理解语境并执行复杂任务的技术实体，人类为了完成这些功能性事务，通常不得不建立直接的人际接触。在这一过程中，功能性交往往往作为一种“强制性载体”，将工具性合作与人际的情感试探、权力博弈、礼仪规范以及偶然性的人际连结捆绑在一起（关于人际摩擦如何构成主体变化的条件，详见 §九）。

而 Agent 生态的介入，对这一捆绑结构实施了**功能性脱媒（functional disintermediation）**：
$$\text{Functional } H\text{-}H \text{ relations} \longrightarrow A\text{-}A \text{ coordination}$$

当双方的代理系统能够代表各自的委托人进行自动化的匹配、筛选与协商时[[Leshchikova et al., 2026](refs.md#leshchikova2026_delegation_asymmetry)]，大量事务性协调可以不再经由人类主体的直接交谈。人类从繁重的功能性沟通中被剥离出来，原本为了“把事情做成”而承担的人际摩擦与情绪劳动被代理间的计算协议所替代。

然而，这种工具性交往的抽离并非单向度的解放。功能性人际互动的减少，意味着人类在社会生活中遭遇异质性他人、体验误解与妥协、并在非意图的摩擦中重塑自身偏好的现实契机相应降低（详见 §九）。

## 6.3 双层社会的结构性浮现与技术自足

随着功能性交往向代理层转移，社会可能形成一种**双层结构（two-tier social structure）**：

1. **代理层（agent layer）**：
   $$\text{Connectivity} \uparrow\uparrow \quad \text{与} \quad \text{Coordination Density} \uparrow\uparrow$$
   在底层网络中，异质代理保持着高频互联。数据流、合约包、竞价协议与验证请求在跨生态之间并发流转，构成了一个高度自动化、高连通性的协同计算网络。
2. **人类层（human layer）**：
   $$\text{Direct Dependency} \downarrow \quad \text{与} \quad \text{Mandatory Encounter} \downarrow$$
   在表层社会中，个体之间的直接物理接触与强制性依赖显著降低。个体通过调用自身的 Agent 生态（$\mathcal{A}$），即可独立调动过去需要依赖庞大组织或复杂人际网络才能实现的行动能力。

这种结构呈现出一种不同于传统社会学描述的原子化状态——**技术自足型原子化（techno-autarkic atomization）**：由技术自足（technical self-sufficiency）——即个体不再依赖特定他人的同意即可组织行动——所导致的原子化形态，区别于以孤立无能为特征的传统原子化。

必须严格区分这一状态与传统社会学意义上的“孤独社会”或个体化理论[[Putnam, 1995](refs.md#putnam1995_bowling_alone)]。传统社会理论所诊断的原子化，通常伴随着孤立个体的脆弱无力与组织支持的溃散。然而，Agent 社会中的原子化并非表现为无能的孤立，而是表现为**个体行动能力被技术放大后的技术自足（technical self-sufficiency）**。

这种自足状态常被误认为是消极自由的技术实现；关于消极自由、自足与伯林对“内在堡垒”式自由批评的详细辨析，在 §7.3 专门处理。

当个体越来越能够依靠专属代理生态闭环解决世俗要求时，面对具有不可预测性之真实他者（concrete others）的现实必要性相应减弱。一个由高度互联的机器生态与高度自足的个体构成的双层社会，究竟会走向极端原子化、非工具性交往比重的相对上升，还是更复杂的混合演进，属于竞争性的社会学假说（详见 §十五 三情景）。
